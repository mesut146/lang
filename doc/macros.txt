//Two parameter kinds, decided by the declared type:
//- `Expr` is a *syntax slot*: every reference to it in the body is replaced by a
//  copy of the argument expression, and the body is copied per call site, so
//  `macro swap(a: Expr, b: Expr){ let t = a; a = b; b = t; }` assigns through
//  its arguments (a twice-used argument is evaluated twice -- if it moves, that
//  is a use-after-move error, not a silent double free);
//- any other type is a *value* parameter: bound once, in declaration order and
//  type-checked, by `let p: T = <arg>;` at the top of the expansion. It behaves
//  like a local of the expansion (assigning to it does not touch the caller, a
//  move type argument is moved into it) and it is evaluated even when the body
//  does not mention it. Since x has no shadowing, the binding uses a fresh name
//  when the parameter's name is already live at the call site, so `take!(s)`
//  never collides.
//Hygiene: the names the *body* declares are alpha-renamed per call site, so a
//macro may use `t`, `i` or `res` whatever the caller has in scope, and a
//substituted argument cannot be captured by a body local of the same name (a
//body local may even reuse a parameter's name: from its declaration on the name
//is the local, before it the parameter). Two limits: a name the body never
//declares still resolves at the call site (macro-level capture, unchanged), and
//a nested binder's spelling keeps its fresh name for the rest of the body (no
//scope restore), so keep inner binder names distinct from outer uses.
//A body ending in an expression makes the macro an expression of the inferred
//type (`macro square(x: Expr){ x * x }`), otherwise it is void.
//Lookup follows the same rules as any other name: a bare `name!` reaches
//top-level macros of this unit and, through `use` prefixes (every `mod` is
//registered as one, as for types), the macros of its modules -- `use m;` or
//`use m::{name}` spell that out -- plus the macros of imported units; a scoped
//`m::name!(...)` (or `a::b::name!`) matches the module the macro was declared
//in, including a module of an imported unit. One `macro name` per unit,
//parameter names must be unique and the builtin names
//(`format`/`print`/`panic`/`debug_member`) are reserved.
//Still open: token-stream macros (resolver/macros.x + TokenStream), printing a
//`use m::{name}` list (it comes out as `use m;`), and definition-site
//resolution of body names (the capture above).
